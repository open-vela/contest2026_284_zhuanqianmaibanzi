Behavior changes:
- Finish stops the inspection workflow but retains UI, SD and data services.
- Safe exit is in the Data page; old shutdown stages now have visible and
  serial progress messages, with the opaque Data overlay dismissed first.
- The completed shutdown page keeps LVGL/input alive and contains Restart
  and Open data actions. The outer application loop destroys the old UI,
  frees its preview memory and reinitializes all services before reuse.
- Open data therefore does not dereference the previously freed storage.
- Result input is frozen when submitted; red boxes cannot follow a later
  live scene. PASS hides boxes. FAIL boxes are bounded to the ROI, inside a
  separate clipped borderless layer. Empty/outside boxes are ignored and a
  corrupt box_count is capped at the fixed array length.
- Opaque Data page and paused occluded preview reduce redraw work. No
  low-level DSI/DMA timing changes; visible tearing remains a board test.
- Receiver explicitly uses Split(char[], StringSplitOptions), not the
  unsupported Split(char, StringSplitOptions) in the old prebuilt EXE.
