# 2026-10-31 触屏流程、红框和 Windows 接收端修复候选

## 问题依据

实板视频 `飞书20261031-203846.mp4` 显示 Data 页横向亮条、上传失败，Windows
日志为缺少 `System.String.Split(Char, StringSplitOptions)`。用户随后确认安全
退出最终到达 `SAFE EXIT COMPLETE`，但 Data 按钮不再响应；另有红色小框位置
令人困惑的反馈（无近照）。不据此认定所有异常都是显示硬件故障。

代码检查确认：旧退出路径销毁 LVGL，却保留原界面最后一帧；旧结果框叠加在
持续变化的实时预览上，并且 PASS 也会显示未超过判定阈值的小差异框。UI
缺少输入框数量上限防护及显式 ROI 裁剪。旧预编译 EXE 的 IL 方法引用与视频
中的缺失签名一致，新 EXE 改为 `Split(char[], StringSplitOptions)`。

## 新操作流程

1. 放好标准件点 `Enroll`；放入待测件点 `Inspect`。检测会冻结**本次输入帧**，
   顶部改为 `CAPTURED / FROZEN`，防止红框继续叠在后来移动的物体上。
2. PASS 不显示红框；FAIL 的差异框只显示在绿色 ROI 内。坐标在缩放前裁剪，
   采用独立无边框裁剪层；空框、越界框跳过，异常框数量最多处理 8 个。
3. 再点 `Inspect` 或 `Enroll` 进入下一次操作；`Stop` 清除框并恢复实时预览。
4. 原主界面 `Exit` 改为 `Finish`：结束检测展示、冻结当前画面，UI、SD 和
   网络服务保持运行，仍可打开 `Data / Upload`。它**不表示可以断电拔卡**。
5. 在 Data 页查看容量，等待 `Pending saves: 0`；启动新版 Windows 接收端，
   点 `Test PC`，确认成功后点 `Upload / Retry`。
6. 需要安全停止时，点 Data 页 `Safe exit`（长按 Stop 仍是备用入口）。退出
   各阶段同时显示在主界面和串口：上传、HTTP、相机、检测、写盘/卸载。
7. 完成后显示专用结束页，不再留下无响应的旧按钮：
   - `Restart`：释放旧 UI、重新初始化应用，回到检测页。
   - `Open data`：重新初始化应用、打开 SD 和网络服务，直接进入数据页。
   - 不点按钮：保持结束页，可断电。建议断电后再拔卡。

`Restart` 是重新启动应用会话，不是硬件复位。`Open data` 不是访问已经释放
的存储句柄，而是完成旧资源回收后建立新会话；模板/阈值/历史会从 SD 恢复。
应用只卸载自己挂载的 FAT，复用其他组件的挂载时不会擅自卸载共享文件系统。
出现 `SHUTDOWN ERROR` 时保留 SD，记录最后退出阶段，不声称已经保存成功。

Data 页现在使用不透明背景，页面打开期间不转换/刷新被遮挡的预览，减少混色
和重绘压力。未修改底层 DSI/DMA 时序；横条是否完全消失仍需新固件实板回归。

## 必须补做的实板验收

1. 正确件 PASS 无红框，异常件 FAIL 的红框与冻结画面对应，全部在 ROI 内。
2. `Inspect → Finish → Data → Upload`，确认主界面不退出，记录上传后能继续检测。
3. 连续三次 `Safe exit → Open data → Back → Inspect`，确认 SD、CSI、网络均可
   重新打开，历史编号不倒退，无内存耗尽/重复任务/蓝屏。
4. 连续三次 `Safe exit → Restart`，模板、阈值与历史恢复，触摸始终响应。
5. 上传中执行 Safe exit，确认取消网络、排空写盘，并到达专用结束页。
6. 频繁打开/关闭 Data，观察原视频横条是否消失；若仍出现，保留串口日志，
   继续针对 PSRAM/DMA 与切屏同步排查，不将本次主机测试作为显示实板验收。
